# Glossary

- **Mnestra** — the project; a point/address from which the whole can be recovered (after Borges'
  "the Mnestra"). The memory model where global structure is readable from any address.
- **Substrate** — the physical medium realizing storage: classical (RAM/phase-change), photonic
  (holographic), or quantum (atomic frequency comb).
- **Content address** — BLAKE2b-128 of a payload's canonical encoding; equal meaning → equal
  address, on any substrate, in any language.
- **Codex** — the structure-complete model of an artifact ("the book"): a plan of slots with
  dependencies, constraints, and shared facts.
- **Slot** — one unit of the Codex (e.g. a section), filled or planned.
- **read_whole_book** — return the compact global view relevant to a slot: outline, constraints,
  dependency summaries, and associatively-recalled regions.
- **REIC** — rare-earth-ion-doped crystal (e.g. Eu³⁺:Y₂SiO₅); the unifying material that supports
  classical, photonic, and quantum storage.
- **Spectral hole burning (SHB)** — classical frequency-multiplexed storage by burning persistent
  holes in an inhomogeneous absorption line.
- **AFC (Atomic Frequency Comb)** — a quantum-memory protocol: shape absorption into a periodic
  comb so an absorbed photon re-emits as a timed echo; stores many temporal modes.
- **Spectral–spatial holography** — analog optical storage of interference patterns across frequency
  and space; recalled by a rephasing pulse.
- **Phase-change material (PCM)** — chalcogenide (e.g. Ge–Sb–Te) with switchable resistance states;
  the room-temperature classical/photonic engineering substrate.
- **Finesse** — ratio of comb period to tooth width in an AFC; higher finesse → higher retrieval
  efficiency (to a ceiling).
- **Structure-complete** — property that the global structure is recoverable from any single point
  (the holographic property, lifted to the logical layer).
